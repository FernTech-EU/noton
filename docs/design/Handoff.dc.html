What changed from the prototype

  1. Formatting is contextual. Fourteen always-on buttons become one Toolbar row that only appears while a text block is being edited, with pressed states (Bold, list) and overflow into ⌄.
  2. State is visible everywhere. Pressed toggles, a SegmentedControl for Canvas | Reading, radio tiles in Settings, bold plus fill for selected rows.
  3. Cards lost their button rows. Move, resize and trash live in the header ⋮ menu, on the keyboard and in Position and size…; drawing tools only exist in drawing mode.
  4. New blocks land in free space (24 px from the nearest block), never on top.
  5. Lists carry information. Note rows show snippet, date and a sketch marker; counts on folders; rename is inline; trash is a place in the Folders pane, not a footer button.
  6. Chrome is organised. Title bar holds menu, library name, search and window controls; the status bar holds save state, the undo target, the block navigator and zoom. Save now and Settings moved into the menu.
  7. Identity. Warm paper surfaces, one vermilion accent, Literata for note content, a real dark palette rather than an inversion.
  8. Accessibility is designed in. Ink-blue focus ring distinct from vermilion selection, named undo, F6 regions, second cues for every state, AA contrast in both themes.
  9. Narrow windows work. Single-column navigation with a Breadcrumb; the canvas zooms to fit and offers Reading view without switching it silently.
  10. Missing UI added. Block navigator, sketch naming and description, checklist and link commands, trash view with permanent delete (P2 boards).
